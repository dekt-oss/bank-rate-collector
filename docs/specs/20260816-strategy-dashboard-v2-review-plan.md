# 1. Current State — 현재 Preview 기준

현재 전략 대시보드는 PR #104까지 반영된 상태를 기준으로 다음 정보 흐름을 가진다.

```text
1. 시장 핵심 지표
   시장 최고 / 시장 평균 / 비교군 / TOP10 진입선

2. 시장 흐름
   63일 금리 추이 + 최근 30일 시장 변화

3. 경쟁 구조
   전국 본점 소재지별 금리 분포 + 경쟁사 TOP5

4. 시장 해석
   시장 인사이트 + 우대조건 트렌드

5. 신상품 기획
   기본금리 / 우대금리 / 기간 / 예상 순위 / 시장 위치
   + 선택적으로 수신금액 예측엔진
```

현재 정보 흐름 자체는 이전보다 명확하다. 사용자가 화면을 위에서 아래로 읽을 때

> 시장이 어디에 있는가 → 최근 어떻게 움직였는가 → 누가 경쟁자인가 → 어떻게 해석할 것인가 → 그래서 어떤 상품을 기획할 것인가

라는 순서가 성립한다.

## 1.1 현재 잘 된 부분

### A. 시장 상황과 기획 영역이 분리되어 있다

신상품 시뮬레이터가 시장 현황 카드 사이에 섞이지 않고 마지막 독립 섹터로 내려가 있어, 현재 시장 데이터와 사용자가 입력하는 가정값을 구분하기 쉽다.

### B. 단순 최고금리 화면을 넘어섰다

시장 최고·평균뿐 아니라 TOP10 진입선, 63일 평균 변화, 최고금리 변화, 당사 변화, 상단 프리미엄을 함께 보여준다.

### C. 최근 시장 변화가 이벤트 숫자에서 방향성으로 발전했다

최근 30일 상품 변경 이벤트의 상승·하락 건수와 비중을 보여주고 `상승 우세 / 하락 우세 / 혼조 / 변화 없음`으로 정리한다.

### D. 시장 인사이트가 기획 포인트까지 연결된다

현재 인사이트는 다음 5개 축을 사용한다.

- 시장 방향
- 경쟁 강도
- 당사 위치
- 지역 편차
- 우대조건 구조

단순 수치 복제보다 의사결정에 가까워졌다.

### E. 전국 지도와 부산 drill-down의 의미 경계가 유지된다

지역 값은 계속 저축은행 **본점 소재지 기준 참고값**이며 판매 가능 지역 또는 지점 적용금리로 표현하지 않는다.

### F. 수신금액 예측엔진의 공신력 경계가 화면에 노출된다

현재 모형은 내부 실적 미보정 구조모형이며 저/기준/고민감 stress band라는 점이 표시된다. 이를 공식 예측모형처럼 표현하지 않는다.

# 2. 현재 Preview의 핵심 부족점

## 2.1 시장 흐름이 아직 한 개의 시간축에 가깝다

현재 화면은 63일 금리 추이와 30일 변경 이벤트를 제공하지만, 사용자가 다음을 빠르게 구분하기는 어렵다.

- 이번 주에 갑자기 움직이는 것인지
- 최근 한 달의 방향인지
- 몇 달간 이어지는 구조적 흐름인지

즉, **속도와 지속성**을 한눈에 분리해서 보기 어렵다.

## 2.2 시장 변화가 `몇 건 올랐나/내렸나` 중심이다

현재 방향성은 유용하지만 다음 질문까지는 직접 답하지 못한다.

- 상위권 은행들이 움직이는가, 하위권 은행들이 움직이는가?
- TOP10 진입선 자체가 올라가는가 내려가는가?
- 시장 평균은 정체인데 최고금리만 튀는가?
- 금리 분산이 커지는가 좁아지는가?
- 변경이 특정 몇 개 은행에 집중되는가, 시장 전체로 퍼지는가?

신상품 금리를 정할 때는 단순 변경 건수보다 **상위권 압력과 변화 확산 정도**가 더 중요한 경우가 많다.

## 2.3 시장 인사이트가 아직 단일 해석이다

현재 인사이트는 기획 포인트를 주지만 사용자가 실제 상품안을 검토하려면 한 단계 더 필요하다.

예를 들어 현재 상황에서

- 1등 추격이 필요한가
- TOP10 정도만 확보하면 되는가
- 금리보다는 우대조건으로 차별화할 것인가
- 현재 금리를 방어하고 조달비용을 줄이는 것이 나은가

같은 **복수 전략 대안**을 동시에 비교할 필요가 있다.

## 2.4 시뮬레이터는 한 번에 한 개 금리안만 본다

현재는 기본금리와 우대금리를 바꾸면서 한 시나리오를 확인한다.

실무에서는 보통 다음처럼 비교한다.

```text
현재안
+5bp
+10bp
+15bp
또는 직접 지정안
```

각 안의 예상 순위·TOP10 gap·당사 대비 인상폭·표면이자비용·수신 시나리오를 한 표에서 비교하는 편이 훨씬 빠르다.

## 2.5 자동 추천을 넣을 경우 과신 위험이 있다

시장 데이터만으로 `최적 금리`를 자동 결정하면 안 된다.

현재 시스템에는 다음이 없다.

- 내부 목표 조달액
- FTP
- ALM 만기구조
- 유동성 필요량
- 영업 목표
- 채널별 신규수신
- 캠페인 효과
- 실제 고객 금리탄력성 보정값

따라서 다음 개선판에서도 시스템은 `최적 금리 추천`이 아니라 **시장 데이터 기반 전략안 비교**까지만 해야 한다.

# 4. 제안 1 — 시장 흐름을 7일 / 30일 / 90일로 분리

## 4.1 목표

하나의 시계열을 길게 보는 방식에서 벗어나 **단기 / 월간 / 분기 흐름**을 빠르게 전환한다.

```text
[7일] [30일] [90일]
```

기본값 제안은 `30일`이다.

## 4.2 각 기간의 의미

### 7일

`최근 급변 감지`

- 신규 특판 또는 공격적 인상 조짐
- 단기간의 경쟁사 반응
- 갑작스러운 하락/인상 이벤트

### 30일

`현재 시장 방향`

- 상품 기획 회의에서 가장 기본적인 판단 기간
- 현재 구현된 시장 변화 집계와 직접 연결

### 90일

`구조적 추세`

- 단기 이벤트가 일시적인지 지속적인지 확인
- 금리 상단/평균/중앙값이 실제로 이동하고 있는지 확인

## 4.3 구현 전 Evidence Gate

현재 Preview의 `rate_trend` 기본 window는 63일이다.

따라서 90일 탭을 확정하기 전에 반드시 실제 canonical 운영 DB에서 다음을 확인한다.

- `rate_observations`의 유효 이력 시작일
- 정상 수집 snapshot이 실제 90일 이상 존재하는지
- 중간 결측일 비율
- 90일 구간에서 product identity 변경이 시계열 왜곡을 만들지 않는지

90일 데이터가 충분하지 않다면 임의로 보간하지 않는다.

가능한 fallback:

```text
7일 / 30일 / 보유 전체
```

또는

```text
90일 탭 유지 + "관측 63일" 명시
```

중 하나를 리뷰 후 결정한다.

## 4.4 기간별 표시 후보

각 기간에서 최소 다음을 같은 규칙으로 계산한다.

- 시장 최고 시작값 / 현재값 / 변화 bp
- 시장 평균 시작값 / 현재값 / 변화 bp
- 중앙값 변화 bp
- TOP10 진입선 변화 bp
- 고려저축은행 현재 대비 변화 bp
- 상승 상품 이벤트 수
- 하락 상품 이벤트 수
- 순변화 방향

# 5. 제안 2 — 시장 변화의 `폭`과 `확산`을 추가

현재 상승/하락 건수 외에 아래 지표를 검토한다.

## 5.1 시장 변화 확산지수 — 제안 지표

공식 금융지표가 아니라 대시보드 내부 상대지표다.

```text
breadth = (상승 이벤트 수 - 하락 이벤트 수)
          / (상승 이벤트 수 + 하락 이벤트 수)
```

범위:

```text
-1.0  전부 하락
 0.0  상승/하락 균형
+1.0  전부 상승
```

UI에서는 숫자 자체보다 다음 수준으로 표현하는 방안을 우선 검토한다.

- 하락 확산
- 하락 우세
- 혼조
- 상승 우세
- 상승 확산

주의: 이 값은 상품 이벤트의 방향 비율일 뿐 금리 수준 자체의 상승률이 아니다.

## 5.2 상위권 압력

다음 값을 같은 기간에서 비교한다.

```text
시장 최고 변화
TOP5 cutoff 변화
TOP10 cutoff 변화
시장 평균 변화
```

예:

- 시장 평균은 -2bp인데 TOP10은 +8bp → 상위권만 경쟁 심화
- 최고금리는 +20bp인데 TOP10은 0bp → 단일 특판 가능성
- 평균·TOP10이 모두 -10bp → 시장 전반 하락

이 구조가 단순 최고금리보다 상품 기획에 유용하다.

## 5.3 분산 변화

후보:

```text
시장 최고 - 중앙값
P90 - P50
P75 - P25
```

단, 현재 payload와 계산 비용을 확인한 뒤 하나만 선택한다.

목표는 `시장 금리대가 좁아지는지 넓어지는지`를 판단하는 것이다.

## 5.4 변경 집중도

최근 변경이 몇 개 금융회사에 집중되는지 확인하는 지표를 검토한다.

예:

```text
변경 이벤트 금융회사 수 / 전체 비교 금융회사 수
```

이 지표는 특정 몇 개의 공격적 은행 움직임과 시장 전반 이동을 구분하는 데 사용한다.

# 6. 제안 3 — 시장 인사이트를 `근거 → 해석 → 기획 영향` 구조로 강화

현재 5개 인사이트 축은 유지한다.

```text
시장 방향
경쟁 강도
당사 위치
지역 편차
우대조건 구조
```

다만 각 카드의 구조를 다음처럼 표준화한다.

```text
[신호]
30일 TOP10 +10bp

[근거]
상승 31건 / 하락 12건
상위10% 진입선 3.75 → 3.85%

[해석]
상위권 중심 금리 경쟁 강화

[기획 영향]
현재안 / +5bp / +10bp를 우선 비교
```

## 6.1 추가할 수 있는 인사이트 후보

- 단기 급등 경보
- 상위권 경쟁 심화
- 금리 하락 국면
- 당사 TOP10 이탈 위험
- 당사 평균 이하
- 시장 분산 확대
- 우대조건 집중도 상승

## 6.2 금지

근거 데이터가 없는 문장을 생성하지 않는다.

예:

- `고객이 고금리 상품으로 이동할 가능성이 높음` — 내부 또는 외부 근거 없이 자동 단정 금지
- `이번 주 10bp 인상이 최적` — 내부 목표/비용 데이터 없이 최적화 표현 금지

# 7. 제안 4 — 자동 `상품전략안` 3종 비교

자동으로 하나의 정답을 추천하지 않는다.

대신 현재 시장 데이터에서 **3개의 명시적 전략안**을 구성한다.

## 7.1 전략 A — 순위 확보형

목표:

- TOP10 또는 TOP5 진입
- 신규자금 확보 우선

예시 기준:

```text
target_rate = TOP10 cutoff 또는 TOP5 cutoff
```

표시:

- 필요 인상 bp
- 예상 공동순위
- 시장 평균 대비 gap
- 당사 현재 대비 gap
- 표면이자비용 변화
- 예측엔진 입력이 있을 때 stress-band 총수신 범위

## 7.2 전략 B — 균형형

목표:

- 현재 시장 평균 이상 유지
- 불필요한 최고금리 추격 방지

후보 기준:

```text
max(시장 평균, 시장 중앙값, 당사 현재금리)
```

정확한 공식은 리뷰에서 결정한다.

## 7.3 전략 C — 방어 / 우대차별화형

목표:

- 기본금리 인상폭 최소화
- 필요 시 우대조건 설계로 headline 최고금리 경쟁력 보완

주의:

우대조건 트렌드는 조건의 **존재 비중**을 보여줄 뿐 실제 고객 달성률을 알지 못한다.
따라서 `우대금리 비용이 더 싸다`는 자동 결론을 내리지 않는다.

## 7.4 전략안 카드의 핵심 원칙

각 전략에는 반드시 다음을 표시한다.

```text
목표
제안 최고금리
현재 대비 bp
예상 순위
TOP10 대비 gap
시장 평균 대비 gap
왜 이 안이 생성됐는지
무엇을 모르는지
```

`추천`, `최적`, `가장 유리` 같은 단정어 대신 `전략안`, `비교안`, `시장 기준안`을 우선 사용한다.

# 8. 제안 5 — 5bp 단위 시나리오 비교표

신상품 시뮬레이터의 가장 실무적인 다음 개선으로 본다.

## 8.1 기본 비교안

```text
현재금리
현재 +5bp
현재 +10bp
현재 +15bp
사용자 직접입력안
```

사용자가 기본금리/우대금리를 조정하면 직접입력안이 갱신된다.

## 8.2 비교 컬럼

```text
시나리오
제안 최고금리
현재 대비 bp
예상 시장 순위
순위 percentile
TOP10 진입선 대비 gap
시장 최고 대비 gap
시장 평균 대비 gap
추가 표면이자비용
예상 총수신 범위
```

수신금액 입력이 없으면 마지막 두 금액 관련 결과 중 예측 금액은 `입력 필요`로 유지한다.

## 8.3 정렬

기본 정렬은 금리 오름차순으로 고정한다.

사용자가 클릭해서 순위 또는 비용순으로 정렬하는 기능은 v2 초기 범위에는 넣지 않는 것을 권고한다.

## 8.4 강조

다음 threshold를 넘는 행만 약하게 강조한다.

- TOP10 최초 진입
- TOP5 최초 진입
- 시장 최고 도달

이렇게 하면 `5bp를 더 쓰면 실제 순위가 변하는가?`를 바로 확인할 수 있다.

# 11. 수신금액 예측엔진과의 관계

이번 개선판의 중심은 **시장 전략 비교**다.

수신금액 예측모형을 더 공격적으로 고도화하는 작업과는 분리한다.

현재 β/γ는 내부 실적 미보정 stress assumption이므로 시나리오 비교표에서도 다음 원칙을 유지한다.

- 단일 정확한 수신액처럼 강조하지 않는다.
- 저/기준/고민감 범위를 우선 표시한다.
- 입력이 없으면 예측 금액을 만들지 않는다.
- `시장전략안`의 선택 기준에 예상 수신액을 강제로 사용하지 않는다.
- 실제 내부 수신실적 calibration 전에는 `최적화`라고 부르지 않는다.

# 18. 현재 권고안

현재 상태에서 우선순위는 다음과 같이 본다.

