# Stage E 외부지표 ECOS 후보 선택 — 시계열 검증 전

정찰일: 2026-08-18

이 문서는 `stage-e-external-indicators-runtime.json`의 실제 `StatisticTableList` / `StatisticItemList` 응답을 사람이 검토한 뒤 **시계열 검증 대상으로 좁힌 후보**다.

아직 production collector 계약이 아니다. 다음 단계에서 실제 `StatisticSearch` 응답의 항목명·단위·최신 시계열을 다시 대조한 뒤에만 collector에 사용한다.

## 1. 금리 경쟁 regime

### 시중은행 1년 정기예금 신규취급액 금리

- 통계표: `121Y002` — `1.3.3.1.1. 예금은행 수신금리(신규취급액 기준)`
- 항목: `BEABAA2118` — `정기예금(1년)`
- 주기: 월
- 단위: 연리%
- 역할: 고객의 시중은행 대체금리 / 저축은행 수신경쟁 외부 benchmark

### 저축은행 1년 정기예금 신규취급액 금리

- 통계표: `121Y004` — `1.3.4.1. 비은행금융기관 수신금리(신규취급액 기준)`
- 항목: `BEBBBE01` — `상호저축은행-정기예금(1년)`
- 주기: 월
- 단위: 연리%
- 역할: 개별 공시금리와 별개인 업권 실제 신규취급 금리 regime

현재 수집기는 개별 기관 공시금리를 관측한다. 위 두 값은 이를 대체하지 않고 Stage E에서 시장 regime control로만 사용한다.

## 2. 업권 수신 증감 regime

통계표 `111Y007` — `1.2.1.2.2. 비은행금융기관 수신(말잔)`의 월별 말잔을 사용 후보로 둔다.

- `1120600` — 상호저축은행
- `1120700` — 신용협동조합
- `1120800` — 상호금융
- `1121000` — 새마을금고
- 단위: 십억원

목적은 기관별 유입액을 추정하는 것이 아니라 **업권 전체 수신이 팽창/위축 중인지 통제하는 것**이다.

파생 feature 후보:

- MoM 수신잔액 증감률
- 3M 변화율
- 필요 시 전년동월비

원시 잔액과 파생률을 구분한다.

## 3. 제외 / 보류

- 은행채·CD·COFIX: v1 제외 결정 유지. 시중은행 실제 신규취급 예금금리를 먼저 직접 관측한다.
- ECOS 코드를 이름만 보고 곧바로 collector에 하드코딩: 금지.
- 현재 정찰에서 자동 code selection: 금지.
- ECOS aggregate로 개별 경쟁사 공시금리를 대체: 금지.
- ECOS aggregate 수신잔액을 고려저축은행 자체 수신유입으로 해석: 금지.

## 4. 다음 Evidence Gate

각 후보에 대해 `StatisticSearch`를 실제 실행하여 다음을 모두 확인한다.

1. 응답 항목명이 위 선택과 정확히 일치
2. 월 주기
3. 단위가 예상과 일치
4. 최근 시계열이 비어 있지 않음
5. 인증키가 산출물에 남지 않음

이 Gate 통과 전에는 production collector 구현으로 넘어가지 않는다.
