## 4. Backfill contract evidence

기존 은행 수신금리 series를 데이터 시작 전 `190001~190012`로 조회한 결과 ECOS는
HTTP 200 본문에서 다음을 반환했다.

```text
CODE = INFO-200
MESSAGE = 해당하는 데이터가 없습니다.
```

즉 historical backfill에서는 `INFO-200`을 네트워크/스키마 오류와 동일하게 취급하지
않도록 별도 no-data contract가 필요하다.

Exact probe는 각 series에 대해 다음을 검증했고 모두 PASS했다.

- `STAT_CODE`
- `ITEM_CODE1`
- `ITEM_NAME1`
- `UNIT_NAME`
- `list_total_count == returned row count`
- 월 중복 0
- 최초~최종 관측월 사이 missing month 0
- 음수값 0

## 7. 화면 설계 체크포인트

실데이터를 본 결과, 후속 화면은 최소 두 층으로 분리하는 것이 타당하다.

1. **이번 달 자금은 어디로 갔나**
   - 공통 최신 관측월 기준 업권별 말잔 증감/증감률
   - 대표금리와 해당월 금리변화 병기

   - 은행 정기예금/정기적금 추이

`금리-수신 반응`은 별도 분석층으로 두고, 잔액 level과 금리 level의 단순 상관이 아니라
`Δbalance(M)`와 `rate(M)`/`rate(M-1)`/`rate(M-2)`를 비교한다. 인과효과라는 표현은
사용하지 않는다.
