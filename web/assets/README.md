# Strategy dashboard map assets

`korea-sido.svg`는 SGIS-derived 원본 시도 geometry와 provenance를 보존한다.
전국 전략 지도 화면은 가독성을 위해 presentation viewBox `120 0 500 785`를 최종 적용한다.
가로 범위는 울릉도 등 동쪽 원거리 도서를 화면 밖으로 제외하고, 세로 범위는 제주 전체가 보이도록 확보한다. 하단 출처 라벨은 제주를 가리지 않도록 오른쪽에 배치한다.
이 설정은 표시 전용이며 금리 데이터·지역 집계·부산 drill-down 계약에는 영향을 주지 않는다.
