미해소 항목

확정 제약
finlife만으로는 부산 구 단위 필터가 불가능하다 상품 API에 지역 필드가 없고, 금융회사 API의 지역 단위는 시도. 저축은행 금리는 rate_scope=head_office_reference로 저장한다.
실행 제약
새마을금고 공식 사이트가 개발 컨테이너에서 차단된다 동일 요청이 Actions 러너에서는 200 OK. 수집과 파서 fixture 확보 모두 Actions에서 수행해야 한다. 우회는 하지 않는다.
명세 정정
금리 페이지 경로가 명세서 §7.3.3 가정과 다르다 goods_19.do?OPEN_TRMID&gubuncode가 아니라 view.do?…&tab=sub_tab_rate. 목록 행의 숨김 span 값을 그대로 되돌려 보내는 방식. 상품군 12/13/14 코드 가정도 근거 미발견.
미검증
금리 페이지 응답 본문을 아직 확보하지 않았다 tblWrap · tbl-tit · divTmp1 선택자 유효성과 divTmp2 등 추가 금리영역 존재 여부가 미확인.
데이터 결함
참고 데이터의 가입기간이 상품별로 결측된다 정기예탁금·꿈드림회전정기예탁금은 모든 entries가 duration null. 기간 없는 금리는 비교 단위로 쓸 수 없으므로 검수항목으로 표면화한다.
법무
참고 저장소에 LICENSE 파일이 없다 package.json에 ISC 선언만 존재. 코드는 복사하지 않고 생성 데이터만 검증용으로 사용한다.
보안
finlife 공식 문서 기준 프로토콜이 http다 평문 전송 시 인증키 노출 위험. https 지원 여부와 일일 호출 한도 모두 미확인.
